# 🌍REEN - Redução e Economia de Energia

## 📌 Sobre o projeto

**Qual é o nome do projeto?**

[REEN - Redução e Economia de Energia]

**Qual problema relacionado às mudanças climáticas o projeto pretende abordar?**

[O Projeto Pretende Abordar o Tema de Economia e Redução de Energia, Que Pode Nos Ajudar a Abaixar o Uso de Energia]

**Por que você escolheu esse problema?**

[Se Quiser Ajudar o Planeta, Esse Assunto é o Mais Fácil Para Começar a Fazer Isso]

## 🎯 Objetivos

**Qual é o objetivo principal do projeto?**

[Ajudar as Pessoas a Economizar Energia Dando Dicas de Que Fazer Para Que Isso Seja Possível]

**Quem é o público-alvo?**

[Toda a População Que Não Sabe Como Reduzir Energia Doméstica]

**Como o projeto poderá ajudar?**

[Incentivando as Pessoas á fazerem mudanças em seu dia-dia para economizar energia elétrica]

## 💡 Solução proposta

**Como o programa funcionará?**

[Coletará Informações Sobre o Cotidiano da População e Fornecerá Ajuda Para Quem Necessita Economizar Energia Elétrica Doméstica]

**Quais serão as principais funcionalidades?**

- [Dar Dicas De O Que Fazer Para Economizar Energia]
- [Quanto Mais Informações Coletadas, Faremos um Gráfico Comparando o Usuário Com o Resto das Pessoas]

**Qual será o diferencial do projeto?**

[O Site Elaborará Dicas Com Base De Sua Economia em Casa]

## 🌱 Relação com as mudanças climáticas

**Quais aspectos do tema serão abordados?**

[A Economia de Energia Doméstica Para reduzir emissões de gases de efeito estufa, diminuir a pressão sobre o sistema elétrico e evitar o uso de fontes mais poluentes, contribuindo diretamente para mitigar as mudanças climáticas.]

**Quais fontes serão utilizadas na pesquisa?**

- [Copilot]
- [Sites que Mostrem Os Objetos Mais Utilizados Que Gastam Mais Energia]
